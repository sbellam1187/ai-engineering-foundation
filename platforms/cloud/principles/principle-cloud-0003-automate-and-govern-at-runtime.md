# principle-automate-and-govern-at-runtime-0102: Automate everything; govern at runtime

## Statement
Cloud infrastructure, deployment, and governance MUST be automated via IaC and CI/CD and enforced via policy-as-code and runtime operational governance.

## Implications
- Infrastructure provisioning uses standardized IaC modules and pipeline templates.
- Security, compliance, and FinOps controls are embedded and continuously enforced.

## Measures of success
- Reduced configuration drift and fewer manual changes.
- Faster onboarding and consistent baselines across teams.
