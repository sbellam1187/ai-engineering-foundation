# principle-cloud-first-default-0100: Cloud-first by default

## Statement
Workloads MUST be designed, built, and deployed using cloud services by default unless there is a compelling regulatory, financial, or technical reason not to.

## Implications
- Teams default to cloud-native services and patterns rather than replicating on-prem designs.
- Exceptions require explicit documentation of drivers and compensating controls.

## Measures of success
- Reduced lift-and-shift workloads.
- Faster delivery through cloud-native services and DevOps practices.
